file.c:
- load/save files
- index newlines
- list folders

render.c:
- all drawing
- handle user input while drawing
- handle changes to layout and settings
- use FreeType2 whenever a new glyph is needed

main_sdl.c:
- main loop

Features:
- copy/paste
- standard selection
- block selection
- multiple selections
- search/replace
    - optionally in regex format
    - optionally within selection
    - within folders, recursively
    - clicking on a word highlights all other instances of that word
- goto line
- macros
    - replay key-strokes
    - edit macro as text
- navigation
    - folders as tabs at the top, files as entries in the folder view on the side
